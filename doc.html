Documentação Técnica — Prefeitura Ceres Backend

Visão Geral

API RESTful desenvolvida em Django para gerenciamento de usuários e solicitações de serviços públicos. Suporta autenticação JWT, cadastro, gerenciamento de solicitações, comentários, status e tipos de requisições.

Principais Apps

user

  • Gerencia autenticação, cadastro e manipulação de usuários.

Modelos

UserType
desc: CharField(100)
Usuario
nome: CharField(255)
dataNasc: DateField
cpf: CharField(14, unique)
endereco: CharField(255)
telefone: CharField(11)
email: EmailField(255, unique)
password: CharField(255)
userType: ForeignKey(UserType)

Principais Endpoints

POST /user/create/ — Cria usuário
GET /user/users/ — Lista usuários
GET /user/login/<cpf> — Login por CPF
PUT /user/<pk>/update — Atualiza usuário
PUT /user/<pk>/change_password — Troca senha
DELETE /user/<pk>/delete — Remove usuário
POST /user/reset_password/ — Reset de senha
GET /user/activate/<uidb64>/<token>/ — Ativação de conta

request

  • Gerencia solicitações de serviços, tipos, status e comentários.

Modelos

RequestType
icon: ImageField
banner: ImageField
desc: CharField(100)
title: CharField(150)
StatusCode
desc: CharField(50)
Request
id_user: ForeignKey(Usuario)
request_type: ForeignKey(RequestType)
importance: IntegerField
img1, img2, img3: ImageField
comment: TextField
lat, lon: CharField(50)
created: DateTimeField
completed: DateTimeField
is_canceled: BooleanField
current_status: ForeignKey(StatusCode)
current_status_updated_at: DateTimeField
Status
id_request: ForeignKey(Request)
status_code: ForeignKey(StatusCode)
dateTime: DateTimeField
Commentary
id_request: ForeignKey(Request)
id_user: ForeignKey(Usuario)
message: TextField
created_at: DateTimeField

Principais Endpoints

GET /request/reqs/ — Lista requisições
POST /request/create/ — Cria requisição
PUT /request/<pk>/update/ — Atualiza requisição
PUT /request/<pk>/cancel/ — Cancela requisição
DELETE /request/<pk>/delete/ — Remove requisição
GET /request/types/ — Lista tipos de requisição
POST /request/create/type/ — Cria tipo de requisição
GET /request/status/ — Lista status
POST /request/create/status/ — Cria status
GET /request/comment/ — Lista comentários
POST /request/create/comment/ — Cria comentário

Autenticação e Permissões

  • Autenticação JWT (rest_framework_simplejwt)
  • Endpoints: /token/, /token/refresh/, /token/verify/
  • Muitas views exigem autenticação (IsAuthenticated)

Fluxo Básico de Uso

  1. Usuário se cadastra via /user/create/
  2. Recebe email para ativação
  3. Faz login e obtém token JWT
  4. Cria uma requisição via /request/create/
  5. Acompanha status e adiciona comentários

Configuração Rápida

  • Configure o banco de dados conforme settings.py
  • Instale dependências: pip install -r requirements.txt
  • Rode as migrações: python manage.py migrate
  • Inicie o servidor: python manage.py runserver

Observações

  • Upload de imagens suportado para solicitações e tipos
  • Filtros por status, tipo, usuário, etc.
  • Ativação de conta via token enviado por email
